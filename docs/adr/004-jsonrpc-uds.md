# ADR-004 — JSON-RPC 2.0 over Unix domain sockets (not gRPC)

**Status:** Accepted

## Decision
Control plane speaks newline-delimited JSON-RPC 2.0 over UDS (named pipes on
Windows in M3), authenticated by a per-run token generated by the supervisor.

## Rationale
Every runtime involved (Bun, Python stdlib, Rust std) speaks it without
native dependencies; wire traffic is human-debuggable with `socat`/`nc`;
schemas are code-generated from TypeBox (§10.4) so the three implementations
stay honest. gRPC/protobuf would add codegen weight for a benefit the
low-traffic control plane never realizes.

## Consequences
- The reference implementations are
  `apps/desktop/src/main/rpc/{client,sidecar-server}.ts`,
  `packages/ipc-rs` (Rust), and `qb_vision/sidecar.py` (Python). They MUST
  stay byte-compatible (hello → ready → request/notify).
- Events are notifications (no id); requests require responses with matching id.
