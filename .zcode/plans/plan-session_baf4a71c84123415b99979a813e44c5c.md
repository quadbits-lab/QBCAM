## Core design decisions

- **Hot path per spec §4:** frames flow `qb-camio (Rust) → shm ring → qb-vision (Python) → shm ring → qb-recorder (Rust) / qb-vcam (mock)`. Bun/Electrobun is control plane only (JSON-RPC over UDS/named pipes with per-run `QB_TOKEN`); preview reaches the webview as ≤720p JPEG over a token-authed WebSocket on 127.0.0.1.
- **Contracts single-source:** TypeBox schemas → JSON Schema → Pydantic (datamodel-code-generator) → committed `dist/`; CI drift guard.
- **SHM ring per §10.2:** 256B header (magic `QBM1`, atomic `writeSeq`, per-reader `readSeq[8]`), 32B slot headers, latest-frame-wins for live, no-drop for recorder. Implementations: Rust crate (hot path), Python (numpy views), TS via `bun:ffi` (diagnostics only).
- **Capture without per-OS native camera code (v0):** `qb-camio` (Rust) spawns FFmpeg (`avfoundation`/`v4l2`/`dshow`) → rawvideo on stdin → ring writer; device enumeration by parsing `ffmpeg -list_devices`. Plus a `FileSource` looped-fixture mode = the spec's fake camera for hermetic tests.
- **Trust rails from day one:** consent attestation gates identity use (TS-01), C2PA/XMP provenance on outputs (TS-02, c2pa-python optional with XMP fallback), honest "QBCAM Virtual Camera" naming (TS-03), in-app synthetic badge (TS-04), fail-safe slate on stall (FR-109/ADR-009), license gate blocking non-commercial weights (§13.3).
- **Shell adapter:** `src/main/shell/` wraps window/tray/RPC creation. Electrobun 2.x implementation (`bunx electrobun init`, `views://`, `defineRPC` per the electrobun skill) + headless implementation (Bun.serve HTTP+WS serving the same built UI). Dev/CI never block on shell API gaps.

## Implementation phases (each with a verification gate)

0. **Bootstrap:** verify/install bun, uv, cargo, ffmpeg (brew); run `pnpm dlx @tanstack/intent@latest list` per AGENTS.md and load matching skills + python-pro/python-development guidance; git init; root workspaces; `bunx electrobun init` into `apps/desktop`. *Gate: Electrobun window opens via `bun run dev`.*
1. **Contracts:** all RPC methods/events from §10.3, settings schema (Appendix B), identity/model/vcam schemas; codegen + drift guard. *Gate: `bun run contracts:gen` is idempotent; round-trip tests pass.*
2. **SHM:** Rust crate + Python mirror + TS diag reader. *Gate: `cargo test` + `pytest` cover writer/reader, multi-reader, latest-wins vs no-drop.*
3. **Core (Bun):** supervisor (spawn/heartbeat 1Hz/restart backoff/crash events), UDS JSON-RPC client, `bun:sqlite` WAL + full §11 schema migrations, settings store, workers (model-manager, job-queue, media-index), shell adapter + `--headless`. *Gate: `bun test` green; hello-sidecar integration test restarts a killed sidecar.*
4. **qb-camio (Rust):** enumerate/open/close RPC, FFmpeg capture + FileSource fake camera → ring. *Gate: `cargo test`; ring seq advances read via TS diag.*
5. **qb-vision (Python):** server + pipeline (YuNet detect on onnxruntime, EP auto CoreML→CPU on this Mac; IoU/centroid tracker with stable IDs; align; **StubSwapper** color-matched overlay + BYO inswapper_128 loader behind license gate; feathered mask; EMA temporal), presets, adaptive governor, fail-safe, stats @2Hz, preview WS. `qb_media` alongside (thumbs, C2PA/XMP, stills). *Gate: pytest on fixtures; 30s fake-camera run reports fps, serves preview JPEGs.*
6. **qb-recorder (Rust):** no-drop ring reader → FFmpeg (VideoToolbox/x264) → fragmented MP4/MKV; disk guard; stop → DB library entry + provenance sign via qb-media. *Gate: 10s recording valid per `ffprobe`.*
7. **qb-vcam mock:** full §8.2 contract (describe/install-unsupported/start/stop/setSlate), JPEG sink + stats; fail-safe integration test (stall → slate). Native stubs documented as M3.
8. **UI:** tokens per §12.1; Studio (WS-JPEG preview canvas, raw/processed/split, stats strip, blend sliders, presets, face badges, record bar, always-visible Bypass), Identities (import → quality score → **consent gate**), Library, Batch, Models, Settings, first-run wizard, i18next scaffold, keyboard nav. *Gate: headless browser smoke — fake camera shows detection boxes and controls work.*
9. **Models:** registry with YuNet entry (URL+sha256, Apache-2.0) + BYO inswapper entry (`commercialUse:false`); `bun run models:dev` downloads YuNet; atomic install + verify in model-manager; license-gate script.
10. **Edge:** signed manifest + version endpoints, telemetry schema allowlist; signature verify script. *Gate: `wrangler dev` + curl + verify script pass.*
11. **Tests/CI/docs:** contract golden tests (TS↔Py), golden-frame test, GitHub Actions (lint biome/ruff/fmt+clippy, typecheck, bun/pytest/cargo tests, drift guard, license gate), ADRs, README quickstart mirroring §24C.
